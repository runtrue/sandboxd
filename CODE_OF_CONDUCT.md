# Code of conduct

## Our standard

We are committed to a respectful, harassment-free community for everyone.
Contributors must communicate constructively, respect differing experiences,
accept responsibility for mistakes, and keep technical disagreement focused on
the work.

Unacceptable behavior includes harassment, discriminatory or sexualized
language, personal attacks, threats, deliberate intimidation, publishing
another person's private information, and sustained disruption of project
spaces.

## Scope

This standard applies in repository discussions, issues, pull requests,
project-managed communication channels, and public settings where someone is
representing the project.

## Enforcement

Report conduct concerns through the repository's
[private reporting form](https://github.com/runtrue/sandboxd/security/advisories/new)
and begin the title with `Conduct report`. This project uses that maintainer-only
channel because it does not publish a separate conduct-reporting mailbox. Do
not include vulnerability details unless the same report also concerns a
security issue. Reports will be reviewed promptly and handled as confidentially
as practical.

Maintainers may edit or remove contributions and may warn, temporarily restrict,
or permanently ban participants whose behavior is inconsistent with this
standard. Enforcement decisions will consider context, impact, repetition, and
the safety of affected participants.

No maintainer may investigate a report in which they are the subject. If no
independent project maintainer is available, the reporter should use GitHub's
abuse-reporting process.

## Attribution

This policy is informed by the Contributor Covenant and the Rust Code of
Conduct.
